# PVD: анализ открытых экспериментальных данных с помощью Python

Учебный проект Чжоу Юйян по курсу «Компьютерные технологии в науке и образовании». Цель — продемонстрировать воспроизводимую обработку опубликованных экспериментальных данных по PVD: проверку качества, описательную статистику, графики и ограниченную регрессионную модель для Pt.

## Данные и ограничения

Основная таблица содержит 30 проверенных записей с опубликованной измеренной толщиной плёнки: Pt (8), Cu₃N (12), W (1), Ti (9). Девять сомнительных записей сохранены отдельно в `pvd_candidates_and_issues_v3.csv` только для контроля качества и не включены в анализ и обучение модели. Для W три значения толщины были оценками авторов; для шести записей CuCrFeMnNi в источнике обнаружено аномальное значение давления.

Состав источников отличается от первоначального плана в ТЗ: девять проверенных записей Ti заменили записи, которые нельзя было безоговорочно включить в основной набор. Тема и исследовательская задача при этом не изменились. Перед финальной сдачей это изменение следует прозрачно объяснить преподавателю.

Все строки основной таблицы имеют DOI, URL и указание места в публикации (`source_locator`). Первичные источники и решение по каждой группе описаны также на листе `Sources` файла `pvd_public_data_v3.xlsx`.

## Структура результатов

Папка `outputs/pvd_public_data_v3/` содержит:

- `pvd_experiments_verified_v3.csv` — исходная проверенная таблица (30 строк, 22 поля);
- `cleaned_pvd_data.csv` — нормализованный экспорт после успешной проверки;
- `error_log.csv` — журнал найденных ошибок (сейчас только заголовки: 0 ошибок);
- `pvd_candidates_and_issues_v3.csv` — девять исключённых/сомнительных записей;
- `pvd_public_data_v3.xlsx` — данные, источники и журнал решений;
- `results.xlsx` — групповые статистики, метрики и прогнозы Pt, корреляции;
- `quality_checks/`, `eda/`, `pt_model/` — машинные отчёты, CSV и PNG-графики.

Три исполняемых ноутбука находятся в `notebooks/`: `01_data_quality_check.ipynb`, `02_descriptive_statistics_visualization.ipynb`, `03_pt_regression_validation.ipynb`. Скрипт `notebooks/run_all.py` выполняет все три по порядку без интерфейса Jupyter и записывает время выполнения и проверенные метрики в `runtime_validation.json`.

## Повторение анализа

Требуется Python 3.14. На машине автора использована Ubuntu/WSL; проект не зависит от абсолютного пути к папке. Из корня проекта создайте отдельное окружение и установите версии библиотек из `requirements.txt`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python notebooks/run_all.py
```

В Windows PowerShell после `py -m venv .venv` активируйте окружение командой `.\.venv\Scripts\Activate.ps1`, затем выполните две последние команды выше. Если политика выполнения PowerShell запрещает активацию, можно вызывать `.\.venv\Scripts\python.exe` напрямую. Для интерактивного просмотра откройте папку в VS Code и последовательно выполните ноутбуки 01, 02 и 03 с выбранным интерпретатором окружения.

Если нужен только отдельный CSV-экспорт, выполните из корня проекта:

```bash
python notebooks/run_quality_check.py
```

Готовая книга `results.xlsx` включена в папку результатов. Её первоначальная сборка использовала отдельный табличный инструмент; запуск ноутбуков обновляет CSV, JSON и PNG, но не пересобирает эту книгу автоматически. Для проверки вычислений используйте свежие машинные файлы, а книгу - как зафиксированный результат.

## Методика и интерпретация

Скорость осаждения вычислена как измеренная толщина / время осаждения. Корреляции и регрессия Pt рассчитаны только для восьми строк одной публикации. В модели использованы давление и ток разряда; предсказанная средняя скорость умножается на известное время образца для получения толщины. Применена проверка leave-one-out; отдельно сравнивается базовая модель по среднему значению скорости обучающей выборки. Эти метрики нельзя трактовать как доказательство универсальной точности для других материалов, установок или публикаций.

## Отчёт и статус сдачи

Краткий научно-технический отчёт находится в `report/Научно_технический_отчёт_PVD_Чжоу_Юйян.pdf`, презентация - в `presentation/final/`. На машине автора десять проверок данных прошли, а регрессия Pt дала MAE 7,47 нм и R² 0,992 при leave-one-out. Это результат внутри одной экспериментальной серии из восьми образцов, а не доказательство переносимости модели на другие установки. Время запуска зависит от машины; измерение сохранено в `runtime_validation.json`.

Видео ещё не записано. Вопросы к экзамену подготовлены отдельно и должны быть опубликованы в учебном чате по правилам преподавателя.
